OpenTubeX F-Droid repository

Install the Android app from the official OpenTubeX repository. F-Droid checks the signed index and handles future updates.

Add the repository

  1. Install F-Droid or another compatible client.
  2. Scan the QR code, or use the button below on your Android device.
  3. Refresh repositories, search for OpenTubeX, and install it.
Add to F-Droid

Manual setup

Paste this address into F-Droid's repository settings:

https://fdroid.opentubex.org/repo?fingerprint=99BCBB15868B41FE7263E409746D4ABCFC4D32262BEF2AB0B494BBA0929347CD

Release channels

OpenTubeX contains signed alpha releases. OpenTubeX Nightly follows the development branch and installs as a separate app, so both channels can remain on the same device.

Requirements

Android 8.0 or newer is required. The current app compiles and targets Android 16.
