OpenTubeX F-Droid repository

Install the Android app from the official OpenTubeX repository. F-Droid checks the signed index and handles future updates.

Add the repository

  1. Install F-Droid or another compatible client.
  2. Scan the QR code, or use the button below on your Android device.
  3. Refresh repositories, search for OpenTubeX, and install it.

Two apps, two channels

OpenTubeX

Signed stable beta releases. Choose this channel for everyday use.

OpenTubeX Nightly

The latest development builds. Try new changes as they land.

Both channels install as separate apps with their own settings and libraries. You can keep both on the same device.

Requirements

Android 8.0 or newer is required. The current app compiles and targets Android 16.
